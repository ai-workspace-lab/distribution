# svc.plus Unified Distribution Engine

Centralized multi-platform, multi-OS package repository and distribution engine for **svc.plus** / **ai-workspace-lab** applications (`xconnect`, `xworkmate`, and future desktop, mobile, and CLI tools).

## Architecture Overview

The distribution plane separates **package repository metadata & installers** (`repo.*`) from **binary artifact mirrors** (`dl.*`) and serves two regional entrypoints:

| Region | Repository Domain | Binary Mirror Domain | Backing Object Store |
| :--- | :--- | :--- | :--- |
| **Global** | `https://repo.svc.plus` | `https://dl.svc.plus` | Cloudflare R2 (`svc-plus-repo-global`) |
| **Mainland China / HK** | `https://cn-repo.svc.plus` | `https://cn-dl.svc.plus` | Aliyun HK OSS (`svc-plus-repo-cn-hk`) |

```
Product Repos (xconnect-app, xworkmate-app, CLIs)
   │
   ├──► GitHub Releases + dl.svc.plus / cn-dl.svc.plus (release-matrix.json + binaries)
   │
   └──► repository_dispatch (product-release) ──► ai-workspace-lab/distribution
                                                       │
         ┌─────────────────────────────────────────────┼─────────────────────────────────────────────┐
         ▼                                             ▼                                             ▼
  Static Site & Installers                      OS Repositories                              Package Managers
  • index.html / repo-index.json                • APT (apt/dists/stable)                     • Homebrew (homebrew/tap.git)
  • install.sh / install.ps1                    • RPM / DNF (rpm/stable)                     • Scoop (scoop/bucket.git)
  • repo/_health/probe.json                     • GPG InRelease & repomd.xml.asc             • WinGet 1.6+ manifests
```

## Quick Install

### macOS & Linux (`install.sh`)

```sh
# Auto-detect mirror (CN vs Global) and OS package manager
curl -fsSL https://repo.svc.plus/install.sh | sh -s -- --product xconnect

# Mainland China mirror
curl -fsSL https://cn-repo.svc.plus/install.sh | sh -s -- --mirror cn --product xworkmate

# Configure OS repository only (APT / YUM / Homebrew tap)
curl -fsSL https://repo.svc.plus/install.sh | sh -s -- --setup-repo
```

### Windows PowerShell (`install.ps1`)

```powershell
# Auto-detect mirror and install XConnect
irm https://repo.svc.plus/install.ps1 | iex

# Mainland China mirror via Scoop
& ([scriptblock]::Create((irm https://cn-repo.svc.plus/install.ps1))) -Product xworkmate -Mirror cn -Method scoop
```

## Package Manager Setup

### Homebrew (macOS)

- **Global (GitHub Tap)**:
  ```sh
  brew tap svc-plus/tap https://github.com/ai-workspace-lab/homebrew-tap.git
  brew install --cask svc-plus/tap/xconnect
  brew install --cask svc-plus/tap/xworkmate
  ```
- **Mainland China Mirror (`cn-repo.svc.plus`)**:
  ```sh
  brew tap svc-plus/tap https://cn-repo.svc.plus/homebrew/tap.git
  brew install --cask svc-plus/tap/xconnect
  ```

### APT (Debian / Ubuntu)

```sh
# Global (replace repo.svc.plus with cn-repo.svc.plus for CN)
curl -fsSL https://repo.svc.plus/apt/svc-plus-archive-keyring.gpg | sudo tee /usr/share/keyrings/svc-plus-archive-keyring.gpg >/dev/null
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/svc-plus-archive-keyring.gpg] https://repo.svc.plus/apt stable main" | sudo tee /etc/apt/sources.list.d/svc-plus.list
sudo apt-get update
sudo apt-get install -y xconnect xworkmate
```

APT repository layout:
- `apt/pool/main/<product>/`
- `apt/dists/{stable,testing}/main/binary-{amd64,arm64}/Packages{,.gz}`
- `apt/dists/{stable,testing}/Release`, `Release.gpg`, `InRelease`

### YUM / DNF (RHEL / Fedora / Rocky / Alma)

```sh
# Global (or https://cn-repo.svc.plus/rpm/svc-plus.repo for CN)
sudo curl -fsSL https://repo.svc.plus/rpm/svc-plus.repo -o /etc/yum.repos.d/svc-plus.repo
sudo dnf install -y xconnect xworkmate
```

### Scoop (Windows)

- **Global (GitHub)**:
  ```powershell
  scoop bucket add svc-plus https://github.com/ai-workspace-lab/scoop-bucket
  scoop install svc-plus/xconnect
  scoop install svc-plus/xworkmate
  ```
- **Mainland China Mirror**:
  ```powershell
  scoop bucket add svc-plus https://cn-repo.svc.plus/scoop/bucket.git
  scoop install svc-plus/xworkmate
  ```

### WinGet (Windows 10/11)

WinGet 1.6+ manifests are generated by `scripts/build_winget_manifest.py` (`<Identifier>.yaml`, `<Identifier>.installer.yaml`, `<Identifier>.locale.en-US.yaml`) and staged under `winget/` on the repository mirrors.

## Repository Layout

- `catalog/products.yaml`: Declarative product & mirror registry (`xconnect`, `xworkmate`, and onboarded CLI/desktop apps).
- `scripts/install.sh`: POSIX `sh`-compatible universal installer for macOS and Linux with SHA-256 verification.
- `scripts/install.ps1`: Windows PowerShell installer supporting Scoop, MSI, EXE, and WinGet.
- `scripts/publish_static_site.py`: Generates `dist/{global,cn}/` static landing pages, `repo-index.json`, `rpm/svc-plus.repo`, health probe JSON, and installer scripts.
- `scripts/build_apt_repo.sh`: Builds and GPG-signs `apt/pool` and `apt/dists/{stable,testing}` metadata.
- `scripts/build_rpm_repo.sh`: Builds `rpm/{stable,testing}/{x86_64,aarch64}` repositories via `rpmsign` and `createrepo_c` with GPG-signed `repomd.xml.asc`.
- `scripts/sync_homebrew_and_scoop.sh`: Syncs `Casks/<product>.rb` and `bucket/<product>.json` from `release-matrix.json` or GitHub Releases, builds Dumb-HTTP bare git repos (`homebrew/tap.git`, `scoop/bucket.git`), and optionally pushes to GitHub tap/bucket repos.
- `scripts/build_winget_manifest.py`: Generates WinGet 1.6+ multi-file YAML manifests from MSI/EXE URLs and SHA-256 checksums.
- `.github/workflows/sync-distribution.yml`: Automated sync pipeline triggered by `repository_dispatch` (`product-release`), `workflow_dispatch`, or pushes to `main`.
- `tests/test_distribution_scripts.py`: Automated validation suite for shell syntax, dry-run installers, static site generation, WinGet manifests, and Dumb-HTTP git mirrors.

## Onboarding a New Product Repository

1. Ensure the product's release pipeline publishes a `release-matrix.json` (schema v1) to `dl.svc.plus/releases/<product>/release-matrix.json` (and optionally `cn-dl.svc.plus`) or standard GitHub Releases assets.
2. Add the product entry under `products:` in `catalog/products.yaml`, specifying `repo`, `platforms`, and packaging metadata for `deb`, `rpm`, `homebrew`, `scoop`, `winget`, and `direct`.
3. Add a `repository_dispatch` step at the end of the product's release workflow:
   ```yaml
   - name: Notify distribution engine
     uses: peter-evans/repository-dispatch@v3
     with:
       token: ${{ secrets.DISTRIBUTION_DISPATCH_TOKEN }}
       repository: ai-workspace-lab/distribution
       event-type: product-release
       client-payload: '{"product": "<product-id>", "channel": "latest", "sync_packages": true}'
   ```

## V2 Go Single-Binary & Cloudflare Workers Engine (`distd`)

The repository includes a lightweight pure-Go unified distribution backend (`cmd/distd` + `cmd/worker`) sharing 100% of the CDN-friendly HTTP router across local single-binary deployments and Cloudflare Workers (`syumai/workers-go` WASM):

- **8 Supported Artifact Ecosystems**: `files` (`HTTPS` / `rsync`), `npm`, `GitHub` (`ghcr.io` images / Git repos / Releases), `Docker / OCI` (standalone R2/OSS/Local hosting + Harbor sync & 302 CDN blob redirect), `Helm` (OCI + classic `index.yaml` dual mode), `APT / deb` (pure-Go OpenPGP signing + Ubuntu PPA / Debian `buildd` mirror & `dput` submission), `DNF / rpm` (pure-Go OpenPGP signing + openSUSE OBS REST API submit & mirror), and `Windows WinGet` (zero-DB WinGet REST Source API v1.x + static 1.6+ YAML manifests).

### Local Single-Binary Run

```sh
make build
./bin/distd serve --listen :8080 --data-dir ./dist-data
./bin/distd sync --only all --storage local
```
